# Image Converter (이미지 변환 및 이름 변경 프로그램)

본 프로그램은 지정한 폴더 내의 이미지 파일들을 불러와 사용자가 지정한 순서 및 이름으로 일괄 변경하고, 웹 최적화 이미지 포맷인 **WebP**로 변환하는 소프트웨어입니다. 

V2 버전에서는 미리보기 기능, 실시간 변환 파일명 확인 기능, 상세 변환 로그 출력 기능에 더하여 **멀티프로세싱(다중 코어) 기반의 초고속 변환** 및 **비동기 썸네일 렌더링** 기술이 적용되어 대용량 이미지 처리 시에도 빠르고 쾌적하게 동작합니다.

---

## 1. 프로그램 시작
프로그램 실행: `main.py` 스크립트를 실행하거나 패키징된 실행 파일을 실행합니다.
```bash
pip install -r requirements.txt
python main.py
```

## 2. 주요 기능 및 사용 방법

### 2.1. 폴더 선택 및 이미지 불러오기
* **[📂 폴더 열기]** 버튼을 클릭하여 변환 대상 이미지가 포함된 폴더를 선택합니다.
* 폴더 선택 시 해당 폴더 내의 이미지 목록이 중앙 리스트에 출력됩니다.
* 선택 개수 표시: 리스트 우측 상단에서 현재 선택된 파일의 개수와 전체 파일 개수를 확인할 수 있습니다.

### 2.2. 파일 선택, 정렬 및 썸네일 미리보기
* **[전체 선택] / [선택 해제]** 버튼을 통해 파일 선택 상태를 일괄 변경할 수 있습니다.
* **[▲ 위로 이동] / [▼ 아래로 이동]** 버튼을 사용하여 이미지가 변환될 순서를 자유롭게 조정할 수 있습니다.
* **[❌ 선택 제외]** 버튼을 누르면 원치 않는 파일을 작업 목록에서 제거할 수 있습니다.
* 리스트에서 특정 파일을 선택하면, 좌측 하단 미리보기 영역에 해당 이미지의 썸네일과 원본 파일 용량이 표시됩니다. (비동기 처리되어 수천 장의 사진을 훑어봐도 프로그램이 멈추지 않습니다.)
* **[↻ 90도 회전]** 버튼을 눌러 이미지의 방향을 시계 방향으로 90도씩 회전시킬 수 있습니다.

### 2.3. 작업 모드 설정 (우측 패널)
우측 탭을 통해 두 가지 주요 기능을 선택할 수 있습니다.

#### 탭 1: 압축 및 이름변경 (WebP 변환)
* **변경할 이름**: 변환될 파일의 기본 이름을 입력합니다. 띄어쓰기를 입력할 경우, 이름 연결 기호로 자동 대체됩니다.
* **이름 연결 기호**: 파일명과 순번 사이에 삽입될 기호를 선택합니다. (`_` 또는 `-`)
* **숫자 패딩**: 자동으로 파일 개수에 맞춰 자릿수를 정렬하거나 원하는 자릿수(예: 01, 001)로 지정할 수 있습니다.
* **저장 위치**:
  * **현재 폴더**: 원본 폴더 경로에 변환된 파일을 저장합니다.
  * **하위 폴더**: 원본 폴더 내에 새로운 하위 폴더를 생성하여 저장합니다. 생성될 폴더명 앞에 날짜 및 시간(년월일시, 년월일)을 자동으로 덧붙이도록 설정할 수 있습니다.
* **원본 파일 유지/삭제**: 변환 완료 후 원본 이미지의 유지 또는 삭제(휴지통으로 이동) 여부를 설정합니다.
* **압축 강도**: WebP 변환 시 적용할 압축 강도를 설정합니다. (1~6 단계, 멀티프로세싱으로 매우 빠르게 처리됩니다.)
* **예상 용량 계산**: 해당 옵션을 체크할 경우, 좌측 미리보기 영역 하단에 변환 후 예상되는 파일 용량이 함께 계산되어 표시됩니다.

#### 탭 2: 단순 이름변경
* 원본 이미지의 확장자나 포맷을 변경하지 않고 **이름만 일괄 변경**하는 기능입니다.
* 원하는 확장자로 일괄 강제 변경하는 기능도 제공합니다.

### 2.4. 변환 실행 및 진행 상황 확인
* 모든 설정을 마친 후 **[🚀 변환 실행]** 또는 **[📝 이름 변경 실행]** 버튼을 클릭하여 작업을 시작합니다.
* 진행 상태바를 통해 전체 작업의 진행률을 확인할 수 있습니다.
* 하단 로그 창을 통해 파일별 용량 감소 내역, 작업 성공 여부, 원본 파일 삭제 여부 등 상세한 기록을 실시간으로 확인할 수 있습니다.

---

## 3. 주의사항
* **원본 파일 삭제** 옵션을 선택한 경우, 삭제된 원본 파일은 시스템의 [휴지통]으로 이동됩니다. 시스템 환경이나 드라이브 종류에 따라 영구 삭제될 수도 있으므로 중요한 파일은 사전에 백업하시기 바랍니다.
* 멀티프로세싱이 적용되어 CPU 점유율이 일시적으로 상승할 수 있으나, 변환 작업 자체는 기존 대비 수 배 이상 빠르게 완료됩니다.
